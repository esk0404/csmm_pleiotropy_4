This study uses GWAS summary statistics for four cancer types:

| Cancer | Dataset | Genome build |
-----------------------------------------
| Breast cancer | GCST004988 | GRCh37 |
| Lung adenocarcinoma | GCST004744 | GRCh37 |
| High-grade serous ovarian cancer | GCST90455658 | GRCh38 |
| Prostate cancer | GCST006085 | GRCh37 |

The original GWAS summary statistics are not included in this
repository because of their large file sizes.

Please download the datasets from their respective GWAS Catalog
accessions before running the analysis.

The ovarian cancer dataset is converted from GRCh38 to GRCh37
using the provided liftover chain.

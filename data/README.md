## Data

This study uses GWAS summary statistics for four cancer types:

| Cancer                           | GWAS Catalog accession | Genome build |
| :------------------------------- | :--------------------: | :----------: |
| Breast cancer                    |       GCST004988       |    GRCh37    |
| Lung adenocarcinoma              |       GCST004744       |    GRCh37    |
| High-grade serous ovarian cancer |      GCST90455658      |    GRCh38    |
| Prostate cancer                  |       GCST006085       |    GRCh37    |

The original GWAS summary statistics are not included in this repository because of their large file sizes.

Please download the datasets from their respective GWAS Catalog accessions before running the analysis.

The high-grade serous ovarian cancer dataset is provided in GRCh38 and is converted to GRCh37 using the provided liftover chain.

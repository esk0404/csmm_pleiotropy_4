# csmm_pleiotropy_4

Pleiotropy analysis using four different GWAS cancer datasets: breast cancer (BCAC), lung adenocarcinoma (TRICL–ILCCO), high-grade serous ovarian cancer (OCAC), and prostate cancer (PRACTICAL).

using conditionally symmetric multidimensional Gaussian mixture model (csmGmm). 
The methodology paper reference is: Sun R, McCaw ZR, Lin X. Testing a large number of composite null hypotheses using conditionally symmetric multidimensional gaussian mixtures in genome-wide studies. Journal of the American Statistical Association. 2025 Apr 3;120(550):605-17.

Pleiotropy settings: Pairwise Pleiotropy (t=1) and Three-way Pleiotropy settings (t=2)

Pairwise Pleiotropy tests whether a SNP affects at least two different cancer datasets. 
Three-way Pleiotropy tests whether a SNP affects at least three different cancer datasets.
